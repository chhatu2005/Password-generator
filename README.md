# Random Password Generator

## About the Project
The Random Password Generator is a simple web application built using HTML, CSS, and JavaScript. It helps users create random and secure passwords by selecting different character types and setting the password length.

## Features
- Generate random passwords.
- Choose password length between 4 and 32 characters.
- Include uppercase letters.
- Include lowercase letters.
- Include numbers.
- Include special symbols.
- Copy generated password to clipboard.
- Validate user input.
- Responsive design for different screen sizes.

## Technologies Used
- HTML5
- CSS3
- JavaScript

## How to Use
1. Enter the desired password length.
2. Select the character types you want to include.
3. Click on the **Generate Password** button.
4. Your password will appear in the result box.
5. Click on **Copy Password** to copy it to the clipboard.
